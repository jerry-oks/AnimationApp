# AnimationApp
Приложение по нажатию кнопки демонстрирует случайную анимацию объекта со случайными параметрами.
Отображает прогресс-бар задержки и анимации и индикаторы их выполнения/окончания.
Поддерживает повтор проигрывания подследней анимации.

## Стэк
+ Xcode
+ Swift
+ MVC
+ Swift Package Manager (SPM)
+ UIKit
+ Storyboard
+ Auto Layout

## Цели и задачи
+ изучение работы анимации, подключения сторонних фреймворков, расширений типов
+ работа с динамическими объектами UIKit
